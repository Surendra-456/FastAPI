FastAPI Common HTTP Status Codes - Notes
✅ 200 OK

Meaning: Request was successful.

Common Usage:

GET → Fetch data successfully
PUT → Update an existing resource successfully
PATCH → Partially update a resource successfully

Example:

GET /posts/1


Response:

{
  "id": 1,
  "title": "FastAPI"
}

✅ 201 Created

Meaning: New resource created successfully.

Common Usage:

POST requests

Example:

POST /posts


Response:

{
  "id": 10,
  "title": "New Post"
}

✅ 204 No Content

Meaning: Request succeeded but no response body is returned.

Common Usage:

DELETE requests

Example:

DELETE /posts/1


Response:

204 No Content

❌ 400 Bad Request

Meaning: Client sent an invalid request.

Common Usage:

Duplicate username/email
Invalid request format
Business logic validation errors

Example:

{
  "detail": "Email already exists"
}

❌ 404 Not Found

Meaning: Requested resource does not exist.

Common Usage:

User not found
Post not found
Invalid resource ID

Example:

raise HTTPException(
    status_code=404,
    detail="Post not found"
)


Response:

{
  "detail": "Post not found"
}

❌ 422 Unprocessable Entity

Meaning: Data validation failed.

Common Usage:

Missing required fields
Wrong data types
Pydantic validation errors

Example Request:

{
  "title": 123
}


Schema:

class PostCreate(BaseModel):
    title: str


Response:

{
  "detail": [
    {
      "msg": "Input should be a valid string"
    }
  ]
}
